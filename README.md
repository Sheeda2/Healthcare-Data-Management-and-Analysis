# Healthcare Data Management and Exploratory Analysis Using PostgreSQL

## Project Overview

This project focuses on managing, cleaning, validating, and exploring synthetic data using PostgreSQL.
Using six datasets to demonstrate basic SQL skills, including table creation, data import, data type conversion, data quality checks, and exploratory analysis.
The analysis explores patient demographics, healthcare encounters, medical conditions, medications, procedures, and clinical observations.

## Dataset Description

The project uses six synthetic healthcare datasets generated by Synthea. The data represents simulated patient records and does not contain real patient information.

The datasets contain the following records:
| Dataset     | Records |
|---|---:|
| Patients    | 111    |
| Encounters  | 5,059  |
| Conditions  | 3,387  |
| Medications | 3,216  |
| Procedures  | 13,641 |
| Observations| 53,961 |
| **Total**   | **79,375** |

## Tools Used

- **PostgreSQL:** Used to create database tables, store data, and execute SQL queries.
- **pgAdmin 4:** Used to manage the PostgreSQL database and import CSV files.
- **Visual Studio Code:** Used to write and organise SQL scripts.

## Database Creation and Data Preparation

The project involved creating staging tables to import the original CSV files and final tables to store the prepared healthcare data.

The preparation process included:
- Importing the six CSV datasets into PostgreSQL.
- Creating staging tables with text-based columns.
- Creating final tables with appropriate data types, such as DATE, TIMESTAMP, UUID, INTEGER and NUMERIC.
- Transforming and inserting data from the staging tables into the final tables.
- Retaining missing values as NULL rather than replacing them with assumed values.
- Selecting relevant columns for the final Patients table and excluding direct patient identifiers.

## Data Quality Checks

Data quality checks were performed on the six final tables to assess record counts, duplicate records, and missing values.
The checks included:
- Counting records in each table to confirm the imported data.
- Checking for duplicate records.
- Identifying missing values in important columns.
- Retaining missing values as NULL where appropriate.
- Reviewing duplicate records without automatically deleting them.
Duplicate records were identified in the Medications, Procedures, and Observations tables. These records were retained for review rather than removed without further investigation.

## SQL Analysis and Key Findings

Basic SQL queries were used to explore the six healthcare datasets and identify patterns in the records.
The analysis included:
- Patient count and gender distribution.
- Distribution of healthcare encounters by encounter class.
- Most frequently recorded medical conditions.
- Most frequently recorded medications.
- Most frequently recorded procedures.
- Most frequently recorded clinical observations.

Key findings included:
- The Patients table contained 111 records, comprising 62 female and 49 male patients.
- Ambulatory encounters were the most frequently recorded encounter class, with 2,446 records.
- Depression screening was the most frequently recorded procedure, with 1,416 records.
- Diastolic and systolic blood pressure were the most frequently recorded clinical observations, with 1,403 records each.

## Limitations

- The datasets are synthetic and do not represent real patient records or actual healthcare outcomes.
- The analysis is limited to the six selected datasets.
- Duplicate records identified in three tables were retained for further review.
- The project focuses on basic SQL data management, data quality checks, and exploratory analysis rather than advanced statistical analysis or predictive modelling.
- Record counts do not necessarily represent unique patients.

## SQL Scripts

The project SQL scripts are organised into six files:
- `01_patients.sql` - Patients table creation, data preparation, and quality checks.
- `02_encounters.sql` - Encounters table creation, data preparation, and quality checks.
- `03_conditions.sql` - Conditions table creation, data preparation, and quality checks.
- `04_medications.sql` - Medications table creation, data preparation, and quality checks.
- `05_procedures.sql` - Procedures table creation, data preparation, and quality checks.
- `06_observations.sql` - Observations table creation, data preparation, and quality checks.
